# Upstream techniques

Studied techniques from 50 browser, WebGPU, and on-device AI repositories. This directory is notes, not a runtime.

- [TECHNIQUES.md](TECHNIQUES.md) is the merge: what is worth using in this engine, and what was left out.
- `notes/` holds README and LICENSE files only where the clone included a license.
- `build-webmcp-tools.SKILL.md` is Google's Apache-2.0 WebMCP skill, copied with its copyright header. It is not implemented here.

Nothing in this folder is wired into `web/` or `api/`. A technique is live only after a measured adapter exists. See `docs/ENGINES.md`.
